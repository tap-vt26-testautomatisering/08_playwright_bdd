# Playwright + BDD
E2E-test med Playwright och Behave.

Filen `requirements.txt` innehåller alla paket som ska importeras.

För att köra, skriv `behave` i terminalen i projektets rotmapp.

Rekommenderad mappstruktur

```text
root/ 
├─ .gitignore
├─ src/
| ├─ features/
| | ├─ pages/
| | └─ steps/
| └─ environment.py
├─ tests/
| └─ unit/
├─ behave.ini
├─ requirements.txt
└─ README.md
```
